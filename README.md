\# AI Internship



\## About

This repo documents my AI/ML internship journey — daily logs, 

projects, and experiments.



\## Setup Instructions

1\. Clone the repo: git clone <repo-url>

2\. Create a virtual environment: python -m venv venv

3\. Activate it: venv\\Scripts\\activate.bat

4\. Install dependencies: pip install -r requirements.txt

5\. Run Jupyter: jupyter notebook



\## Folder Structure

\- data/ - raw and processed data

\- notebooks/ - Jupyter notebooks

\- src/ - reusable Python modules

\- experiments/ - configs and results

\- projects/ - main project folders

\- logs/ - daily progress logs
